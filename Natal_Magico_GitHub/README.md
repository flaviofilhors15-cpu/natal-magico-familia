# Natal Mágico em Família — site

Site estático de página única. O arquivo `index.html` está na raiz e contém os recursos incorporados.

## Publicar via GitHub + Netlify
1. Crie um repositório no GitHub (ex.: `natal-magico-familia`).
2. Envie `index.html` e este `README.md` para a raiz do repositório.
3. Na Netlify, escolha **Add new site → Import an existing project**.
4. Conecte o GitHub e selecione o repositório.
5. Deixe **Build command** em branco e **Publish directory** como `.` (raiz).
6. Clique em Deploy.
